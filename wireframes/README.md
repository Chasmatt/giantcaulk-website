# Wireframes

Original design mockups the owner supplied for the v2 site. Kept in the repo
as a reference for why the built pages look the way they do.

| File | Corresponds to |
| --- | --- |
| `home.png` | `src/pages/index.astro` — full-viewport photo hero, dual-font PRECISION CAULKING / Lasting Protection, Request A Quote button |
| `about.png` | `src/pages/about.astro` — two-column photo + paragraph layout |
| `services.png` | `src/pages/services.astro` — dark navy hero band + 3-card flip grid |
| `contact.png` | `src/pages/contact.astro` — floating white form card over desk photo, blueprint upload |

This folder lives outside `/public/`, so Astro doesn't bundle these into the
built site — nobody visiting the live URL can browse to them. They're only
here in the git repo for internal reference.
